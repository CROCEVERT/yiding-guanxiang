# 易定观象 macOS 本地预览验收

本清单只用于用户本机验收，未完成全部项目之前不发布 GitHub。

## 启动与窗口

- 打开 `release/mac-arm64/易定观象.app`，应用能正常启动，不闪退、不白屏、不黑屏。
- 窗口标题为“易定观象”，背景、品牌字、铜钱和文字没有被裁切。
- 第一次启动的使用须知可滚动阅读，“我已了解”按钮可点击。

## 核心流程

- 首页点击“开始互动”进入问题页；输入问题和选择类别均可用。
- 连续完成六次投币，爻线、动爻标记和状态显示正常。
- 揭示页能进入结果页；静卦与动卦的卦辞、象曰、动爻、之卦与折叠内容均可阅读。
- 可保存记录、打开记录详情、删除记录并重新开始一次流程。

## macOS 行为

- 关闭窗口后，从 Dock 再次打开，应用可恢复或重新创建窗口。
- 从 DMG 拖入“应用程序”文件夹后仍能正常启动。
- 不接受任何异常的网络、摄像头、麦克风、定位或通讯录权限请求。

## 验收结论

- 记录系统版本、Mac 芯片类型和 macOS 版本。
- 若出现裁切、无响应、黑屏、流程无法继续或记录丢失，截图并标注复现步骤；此时不进入 GitHub 发布。
