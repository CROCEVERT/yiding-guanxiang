# 结果页顶部整合设计

## 目标

把结果页首屏的卦名、复盘问题、上象、下象和完整六爻图整合进同一张主卡片，减少重复信息与纵向留白。

## 布局

- 主卡片顶部保留“易象复盘报告”和本次卦名。
- 卡片主体采用左右双栏。
- 左栏展示本次复盘问题，下方紧凑展示上象与下象。
- 右栏展示本次真实六爻，从上爻到初爻纵向排列。
- 删除原有重复的“当前之象”区块。

## 六爻命名

六爻名称由位置和阴阳共同决定：

- 初爻：阳为“初九”，阴为“初六”。
- 二至五爻：阳使用“九”，阴使用“六”，例如“九二”“六五”。
- 上爻：阳为“上九”，阴为“上六”。
- 变化爻继续显示“变”标记。

## 响应式

- 当前移动端宽度保持左右双栏，左栏略宽于右栏。
- 问题文本允许自然换行。
- 六爻线条使用固定高度和稳定列宽，避免名称变化导致布局跳动。
