# 视觉资产使用说明

## 1. 资产定位

当前视觉方向调整为简约高级新中式案台。重点是深色石案、极简铜制卦盘、竹简、素纸、淡淡烟气和低亮度卦纹。

视觉应服务“文化学习与问题参照”，避免传奇游戏感、强烈金光、神兽压迫感和作法感。

## 3. 页面使用建议

- 首页：深色石案与铜制卦盘为中心，铜钱只作为互动道具点到为止。
- 问题页：输入区域可以参考素纸、签纸或案头便笺，但保持克制。
- 六爻生成页：铜钱轻旋，生成后稳稳落位，动效要慢。
- 易象揭示页：符号环归位，低亮度点亮当前之象。
- 结果页：信息像一份案头复盘札记，重点放在可读性和行动建议。

## 4. 动画原则

- 速度慢于娱乐化互动，强调沉稳和停顿。
- 避免强闪光、强粒子和夸张震动。
- 动效用于表达层级、归位和反馈，不做炫技。
- 移动端优先保证阅读、点击和滚动稳定。
