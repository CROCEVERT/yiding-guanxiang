# 《周易》电子底本候选与下载记录

本目录只存放经版本、来源和校勘过程的记录；它不自动成为程序内容来源，也不收录不明下载站的现代译文。

## 当前优先参照

1. [《周易正义》阮元校刻《十三经注疏》本](https://ctext.org/library.pl?collection=127&if=gb&remap=gb)
   - 定位：项目经典层的**显示参照**，用于统一异体字、异文和断句政策。
   - 说明：这是公开可回看的版本线索，不意味着项目自行声称为学术校勘本。

2. [Chinese Text Project｜Book of Changes](https://ctext.org/book-of-changes/ens)
   - 适用：逐条查核卦辞、爻辞、彖传、象传，并回看列出的具体版本／影印资源。
   - 注意：网页文字可能含 OCR 自动匹配，最终改动必须与影印或第二来源核对。

3. [维基文库｜周易正义](https://zh.wikisource.org/wiki/周易正義)
   - 适用：完整卷目与可读电子参照；覆盖 64 卦及《系辞》《说卦》《序卦》《杂卦》。
   - 页面标示作品为公有领域；维基文库的转录文本仍应与另一来源比对，不能独立视为校勘终稿。
   - 原站提供 EPUB、MOBI、PDF 导出入口。2026-08-11 尝试原站下载时，导出服务拒绝访问，未改用第三方镜像或绕过站点限制。

## 使用原则

1. 程序中的经典原文只在差异经人工核对后改动。
2. 每次改动均记录：版本、来源链接、涉及字段、复核日期和原因。
3. 现代白话、行动提示与课程笔记保持为项目自己的写作层，不与经典原文混写。
